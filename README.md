# 🎉 Ambiance — jeux de soirée (PWA)

Une application web installable (PWA) avec **61 jeux de soirée** en français, **tous jouables en ligne, chacun sur son téléphone** (ou sur un seul téléphone qu'on se passe).
Aucun framework, aucune étape de build : ce sont des fichiers statiques à héberger n'importe où.

## L'accueil : 3 modes

| | Mode | Pour quoi |
|---|---|---|
| 📱 | **Local** | Un seul téléphone qu'on se passe : 54 jeux (quiz, Sur le front, À vue de nez, jeux de cartes…), avec recherche, « On est combien ? », 🎲 au hasard, favoris et joués récemment. |
| 🌐 | **Online** | Chacun sur son téléphone : **Créer le salon** ou **Rejoindre le salon** (code ou QR code). Celui qui a créé le salon lance les jeux, les autres **votent** pour ceux qu'ils veulent. |
| 📺 | **TV Mode** | Sur un ordinateur ou une télé : **▶ Lancer la télé**, chacun scanne le QR code avec son téléphone. Le premier arrivé est le **chef 👑** (il lance les jeux, les autres votent), la télé affiche tout en grand. |

## Lancer en local

```bash
cd ambiance
python3 -m http.server 8080
```

Puis ouvrir <http://localhost:8080>. (Un serveur est nécessaire : les modules JavaScript ne se chargent pas en `file://`.)

Pour tester sur ton téléphone sur le même Wi-Fi, il faut du **HTTPS** pour le service worker, le gyroscope et l'installation : le plus simple est de déployer (voir ci-dessous).

## Déployer (gratuit)

Le dossier est un site statique : il suffit de l'héberger tel quel.

- **Netlify Drop** : glisser-déposer le dossier `ambiance` sur <https://app.netlify.com/drop>.
- **GitHub Pages** : pousser le dossier dans un dépôt, puis *Settings → Pages → Deploy from branch*.
- **Vercel / Cloudflare Pages** : importer le dépôt, sans commande de build, dossier de sortie = racine.

Ensuite, sur le téléphone : ouvrir l'URL puis « Ajouter à l'écran d'accueil » (Android le propose directement dans l'appli).

## ⚠️ Après chaque modification

Régénérer le service worker pour que les téléphones récupèrent la nouvelle version :

```bash
node scripts/gen-sw.mjs
```

Le script liste tous les fichiers et calcule un numéro de version. Les utilisateurs voient alors « Nouvelle version disponible → Mettre à jour ».

## Comment marche le mode en ligne

- Connexion **pair-à-pair** (WebRTC) via [PeerJS](https://peerjs.com). Le serveur public gratuit `0.peerjs.com` sert seulement à mettre les téléphones en relation, puis les données passent directement entre eux.
- L'**hôte** (celui qui crée la partie) fait tourner le jeu : il garde l'état complet et envoie à chaque joueur uniquement ce qu'il a le droit de voir (le mot à dessiner n'est envoyé qu'au dessinateur, chaque joueur ne reçoit que son mot à L'Imposteur…).
- Code à 4 lettres + QR code + lien de partage. Reconnexion automatique si un joueur perd le réseau ou recharge la page (le dessin en cours est restauré).
- **Partie coupée, partie reprise** (`js/online/save.js`) : le téléphone de l'hôte enregistre la partie en continu (joueurs, scores, jeu en cours). S'il ferme l'appli, si son téléphone se verrouille ou si la page se recharge, l'accueil propose « 🔁 Reprendre la partie » : même code, mêmes scores, le jeu repart au même point (les minuteurs sont mis en pause). Les autres sont prévenus (« Alice a quitté l'appli un instant… »), patientent jusqu'à 5 minutes et reviennent tout seuls.
- **Un joueur qui revient retrouve sa place et ses points** : bandeau « 🔌 Revenir dans la partie » sur l'accueil, et l'hôte reconnaît aussi un joueur parti qui revient avec le même prénom depuis un autre navigateur.
- 📺 **Mode télé** (`js/online/tv.js`) : accueil → **TV Mode** → « ▶ Lancer la télé » (la télé crée le salon, les téléphones scannent le QR code, le premier arrivé est le chef 👑), ou « Afficher un salon déjà créé » (code, ou `#/tv/CODE`). La partie s'affiche en grand pour tout le monde (code et QR pour rejoindre, classement en direct, podium) et les téléphones servent de manettes. **55 jeux sur 61 ont un vrai écran télé**, pensé pour le grand écran : le Quiz et les jeux de rapidité (question et 4 grandes réponses), Je dessine (le dessin en direct, mot caché), les votes (barres qui s'allongent), les cartes à tour de rôle (Action ou vérité, Cap…), la Bouteille et la Roue qui tournent en grand, Le Roi, Plus ou moins et Le Bus (cartes qui se retournent), Memory, Yam's, Bataille navale, Morpion et 4 en ligne, le Pendu, le Petit bac, les jeux par équipes (scores, chrono), Le Bon Mot (saisie en direct), Loup-garou… Les autres (Réflexes, Couleurs pièges, L'Imposteur, Menteur, Téléphone dessiné, Qui suis-je) gardent l'écran commun, car tout s'y joue sur les téléphones ou en secret. La télé ne reçoit jamais de secret (mot, rôle, réponse pas encore révélée).
- Ça marche en Wi-Fi comme en 4G/5G, même à distance (relais automatique, voir ci-dessous).

### En 4G/5G ou sur des Wi-Fi différents

La connexion directe entre téléphones (WebRTC) est souvent bloquée par les opérateurs mobiles ou entre deux box. Dans ce cas, l'appli bascule toute seule sur un **relais** (`js/online/relay.js`) : les messages passent par des serveurs MQTT publics et gratuits (shiftr.io sur le port 443, qui passe même sur les réseaux filtrés, puis EMQX, HiveMQ et Mosquitto ; liste dans `js/config.js`). L'hôte écoute sur tous ; un joueur essaie la connexion directe pendant 8 secondes puis passe au relais, sur le premier serveur où l'hôte répond. Si le serveur PeerJS est injoignable, tout passe par le relais.

Les messages qui passent par ces serveurs publics sont **chiffrés** : chaque connexion commence par un échange de clés (ECDH P-256, la clé secrète n'est jamais envoyée), puis tout est chiffré en AES-GCM. Un curieux qui écoute le relais ne voit ni les prénoms, ni les mots secrets, ni les rôles. (La connexion directe WebRTC est déjà chiffrée par le navigateur.) Ces serveurs n'offrent en revanche aucune garantie de disponibilité. Pour une fiabilité maximale, tu peux aussi ajouter un serveur TURN dans `js/config.js` (par ex. un compte gratuit Metered, Twilio ou ton propre `coturn`), ou remplacer `relayBrokers` par ton propre serveur MQTT.

Tu peux aussi héberger ton propre serveur de mise en relation PeerJS :

```bash
npx peer --port 9000
```

puis renseigner `peerHost` / `peerPort` dans `js/config.js` (ou tester avec `?peerhost=localhost&peerport=9000&peersecure=0` dans l'URL).

## Ajouter du contenu

Tout le contenu est dans `js/data/` (un fichier par jeu, simples listes JavaScript) :

- `tupreferes.js`, `jamais.js`, `dix.js`, `qui.js`, `paranoia.js`, `action.js`, `gages.js` : cartes par niveau
- `dessin.js` : mots à dessiner (facile / moyen / difficile)
- `motsinterdits.js`, `mime.js`, `chapeau.js`, `front.js`, `imposteur.js`, `patate.js`, `petitbac.js`, `cinq.js`, `debats.js`
- `mots.js` : dictionnaire du Bon Mot, **généré** par `scripts/gen-mots.mjs` (voir l'en-tête du script). Sources : [an-array-of-french-words](https://github.com/words/an-array-of-french-words) (MIT) pour les 320 000 mots, [Liste de prénoms et patronymes](https://www.data.gouv.fr/fr/datasets/liste-de-prenoms-et-patronymes/) (Licence Ouverte) pour les ~5 800 prénoms, `scripts/argot.txt` (argot et verlan, **à compléter si un mot manque**), et [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (CC BY-SA 4.0) pour les mots courants et tous les mots vus au moins 3 fois dans les sous-titres français.

Les niveaux d'intensité sont définis dans `js/data/levels.js`.

## Ajouter un jeu

1. Créer `js/games/monjeu.js` qui exporte `start(ctx)` (dessine dans `ctx.root`, renvoie éventuellement une fonction de nettoyage).
2. L'ajouter dans `js/games/index.js` (nom, emoji, couleurs, catégories, règles).
3. Son image pour l'accueil : ajouter sa composition dans `scripts/images/scenes.mjs`, puis `node scripts/gen-images.mjs monjeu` (→ `img/jeux/monjeu.webp` ; mode d'emploi en tête du script).
4. `node scripts/gen-sw.mjs`.

Pour un jeu en ligne : créer un module dans `js/online/` (sur le modèle de `vote.js`) avec `init`, `action`, `tick`, `view` (côté hôte) et `mount` (côté écran), puis l'ajouter à `js/online/games.js`.
